# Style

Follow the canonical Nyx style in the pinned `nyx-design` dependency (Design 2.0).
Reuse `nyx-theme`, `nyx-ui`, shared shortcuts, semantic colors and GTK4 widgets.
The Share Sheet is a fixed-width floating window (560 px); destination tiles use
the nyx-icons satin plate in every theme. The approved mockup is in
`nyx-design/mockups/share/`.
